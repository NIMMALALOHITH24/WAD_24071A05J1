# Courier Management 

This is a small demo React application (Vite) for a courier management system with:

- Login (mock)
- Parcel booking
- Tracking
- Payment (simulated)
- Contact page

Run locally:

```bash
cd folder1
npm install
npm run dev
```

Open `http://localhost:5173` (or the port Vite reports).

Notes:

- Authentication is mocked via `localStorage('token')`.
- Data (parcels) stored in `localStorage` for demo purposes only.
